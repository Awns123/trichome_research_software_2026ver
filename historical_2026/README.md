# Historical 2026 layer

이 폴더는 원 아카이브에서 선별한 역사적 처리자료·코드·결과를 원문 수정 없이 보존합니다.

- `morphology_phylogeny_analysis/`: 2026-04-12 분석 세션에 가까운 코드. `/mnt/data` 고정 경로 포함
- `figure_generation/`: 원 notebook 부재 상태에서 2026년 4월 저장 산출물을 바탕으로 재구성한 도표 코드
- `portable_reproduction/`: 2026-05-05 휴대용 사후 재계산 코드
- `03_processed_data/`: portable script가 요구하는 165 image medians, 종 중심값과 거리행렬
- `05_results/`: 당시 보관된 요약표와 선별 그림

`solanaceae_molecular_distance_matrix_from_tree.csv`는 나중에 strand 방향 문제가 확인된 역사적 입력입니다. 원 수치를 재현하기 위해 보존했을 뿐 현재 유효한 분자거리 행렬로 제공하지 않습니다.

휴대용 재계산 명령은 저장소 루트 README에 있습니다. 원 분석 세션 코드는 경로를 수정하지 않은 보존본이므로 그대로는 다른 컴퓨터에서 실행되지 않을 수 있습니다.
